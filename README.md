# Armeria di Rhodes — Listino

Sito standalone per l'Armeria di Rhodes.

Questa branch e' stata preparata separatamente dal sito Tenuta Vauclair:
- solo listino Armeria;
- nessuna pagina Ordini / Eventi / Archivio / Regole;
- nessun database condiviso o notifica;
- sconti mantenuti;
- costo di produzione visibile;
- margine di profitto rimosso;
- pulsante Chiudi/Apri sezioni mantenuto;
- Vista compatta e Registro rimossi;
- tema grafico Rhodes / Lemoyne.

La branch `main` della Tenuta Vauclair non e' stata modificata.
